TIMEWISE — WEBSITE MANAJEMEN WAKTU

ISI FOLDER
- index.html : struktur halaman website
- style.css  : seluruh desain dan responsive layout
- script.js  : fitur interaktif website

CARA MENJALANKAN
1. Ekstrak file ZIP ke folder yang mudah ditemukan.
2. Pastikan index.html, style.css, dan script.js berada di folder yang sama.
3. Klik dua kali index.html untuk membukanya di browser (Chrome, Edge, atau Firefox).
4. Tidak perlu database atau instalasi tambahan.

FITUR
- Dashboard ringkasan total, tugas selesai, dan progres.
- Tambah, edit, hapus, cari, filter, urutkan, dan tandai tugas selesai.
- Deadline dan label prioritas.
- Jadwal harian yang dapat ditambah dan dihapus berdasarkan tanggal.
- Timer fokus dengan mode 25 menit, istirahat 5 menit, dan istirahat 15 menit.
- Halaman tips manajemen waktu.
- Data tugas dan jadwal disimpan menggunakan LocalStorage pada browser yang sama.

CATATAN
- Website ini merupakan prototipe front-end dan belum menggunakan login atau database online.
- Data tersimpan pada browser/perangkat yang digunakan. Menghapus data situs/browser dapat menghapus data tersebut.
- Font dari Google Fonts memerlukan koneksi internet; website tetap dapat digunakan jika offline, tetapi font akan memakai font pengganti.
